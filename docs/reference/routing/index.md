## Minimal example {#minimal-example}


```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/")
async def read_items():
    return [{"id": 1}]


@app.post("/items/")
async def create_item(payload: dict):
    return {"id": 2, **payload}
```


## Path parameters and path converters {#path-parameters-and-path-converters}


```python
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}
```


## Routers {#routers}


```python
from fastapi import APIRouter

router = APIRouter()


@router.get("/health")
async def health():
    return {"ok": True}


app.include_router(router, prefix="/api", tags=["meta"])
```


## WebSockets {#websockets}


```python
from fastapi import WebSocket


@app.websocket("/ws")
async def ws(websocket: WebSocket):
    await websocket.accept()
    await websocket.send_json({"hello": "world"})
    await websocket.close()
```


## Middleware and events {#middleware-and-events}


`add_middleware`, `middleware`, `on_event`, `add_event_handler` and
`exception_handler` are available on both the application and the router.
