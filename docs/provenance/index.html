How the inventory was produced

The generator parses the pinned tree with Python's ast module — the package is never imported, so no dependency has to be installed to produce the inventory. For every module it records the public classes, their public methods and the public functions, each with a rendered signature and the first line of its docstring. The upstream documentation tree under docs/en/docs/ is copied verbatim.
